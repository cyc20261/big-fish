# 🐟 大肥鱼 — DeepSeek AI Chat PWA

一个呆萌的 DeepSeek AI 聊天伴侣，纯前端实现，无需后端。

[▶ 在线体验](https://cyc20261.github.io/big-fish/)

## ✨ 功能

- 🐟 **呆萌人格**：预设可爱鱼格，支持自定义人设
- 💬 **QQ 风格聊天界面**：顶部导航、左右气泡、时间分割线、输入栏，和手机 QQ 一致
- 🙋 **可设备注**：随时给鲸鱼娘改备注名，显示在聊天顶部
- 🖼 **鲸鱼娘壁纸**：10 款角色插画做背景（头像立绘/幼体/成体/标志/社区作品/表情包），点 🖼 一键切换
- 🎨 **5 种配色**：海洋蓝、极光紫、夕阳橙、樱花粉、粉樱，自己的气泡跟着变色
- 🔑 **自带 Key**：API Key 存浏览器 localStorage，不上传服务器
- 📱 **PWA 安装**：手机浏览器打开 → 添加到主屏幕，像原生 App
- 💬 **记录保存**：对话记录自动保存，刷新不丢
- ⚙️ **可调参数**：随机度、模型（chat / reasoner）随意调
- 🌐 **单文件部署**：一个 HTML 搞定，拖到任何静态托管即用

## 🚀 部署

1. 把 `index.html` 和 `sw.js` 拖到 GitHub Pages / Vercel / Netlify
2. 或者直接用 tiiny.host 上传
3. 打开网页 → 填入 DeepSeek API Key → 开始聊天
